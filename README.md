# Vantage Bank 🏦

A secure, full-stack banking application featuring JWT authentication, real-time transaction history, and a cyberpunk glassmorphism UI.

## 🚀 Tech Stack
* **Backend:** Java, Spring Boot 3, Spring Security, JWT, JPA/Hibernate, PostgreSQL.
* **Frontend:** React (Vite), TypeScript, Tailwind CSS, Axios.
* **Database:** PostgreSQL.

## ✨ Features
* **Secure Auth:** User Registration & Login with BCrypt & JWT.
* **Account Management:** Create Savings/Checking accounts.
* **Transactions:** Deposit, Withdraw, and Transfer funds between users.
* **Real-time Dashboard:** View balance updates and transaction history instantly.

## 🛠️ How to Run

### Backend
1. Open `backend` folder in IntelliJ.
2. Update `application.properties` with your PostgreSQL credentials.
3. Run `VantageBankApplication.java`.

### Frontend
1. Open `frontend` folder.
2. Run `npm install`.
3. Run `npm run dev`.
